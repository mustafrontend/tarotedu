# 🔮 TarotEdu — Professional Tarot Learning Platform

**Master the Tarot with Expert Guidance**

A comprehensive, niche tarot education platform built with modern web technologies. Learn the complete Rider-Waite system with step-by-step lessons, daily readings, and interactive spreads.

## ✨ Core Features

- **📚 Tarot Academy** — 22 Major Arcana cards with detailed lessons
- **🎯 Daily Draw** — Receive personalized daily card guidance
- **✨ Tarot Spreads** — Celtic Cross, Three Card, Horseshoe, Career & Love readings
- **🧠 Numerology** — Calculate Life Path numbers from birth dates
- **💾 Progress Tracking** — Track learned cards and reading history
- **🌍 Multi-Language** — English, Turkish, Spanish, German, French support
- **🎨 Beautiful UI** — Mystical design with smooth animations and Tailwind CSS

## 🛠️ Tech Stack

- **React 18** + TypeScript — Component-based UI
- **Vite** — Lightning-fast development server
- **Tailwind CSS** — Utility-first styling
- **Framer Motion** — Smooth animations
- **Zustand** — Lightweight state management
- **i18next** — Internationalization (TR, EN, ES, DE, FR)

## 🚀 Quick Start

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

Development server runs on `http://localhost:5173`
