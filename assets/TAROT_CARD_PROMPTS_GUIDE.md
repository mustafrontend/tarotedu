This document contains production-grade prompts designed for generating high-definition 3D mystical tarot card visuals and cinematic videos (compatible with **Midjourney v6**, **DALL-E 3**, **Runway Gen-2/Gen-3**, **Pika Labs**, **Stable Diffusion XL**, and **Antigravity Engine**).

## 🎨 Global Visual Style & Aesthetic Guidelines

- **Style**: Mystical 3D Render, Kinetic Lithography, Ornate Gold & Deep Purple Accents, Rider-Waite Symbolism.
- **Lighting**: Soft Glowing Aura, Cinematic Volumetric Lighting, Celestial Starry Background.
- **Aspect Ratio**: `--ar 2:3` or `9:16` (ideal for mobile tarot cards).
- **Color Palette**: Deep Violet `#581C87`, Electric Purple `#9333EA`, Radiant Gold `#F59E0B`, Astral Blue `#1E1B4B`.

## 📁 How to Save Assets in TarotEdu

1. Generate your image using the prompt above.
2. Save the generated images into `tarotedu/public/cards/` or `tarotedu/src/assets/cards/`:
   - `0-the-fool.png`
   - `1-the-magician.png`
   - `2-the-priestess.png`
   - ... up to `21-the-world.png`
3. Update `src/data/majorArcana.ts` image path string accordingly!
